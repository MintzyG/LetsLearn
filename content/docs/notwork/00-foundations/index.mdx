Before you build anything, a few ideas. This chapter is reading only: no code, no tests, about an hour.

Already know your way around networks? Skip ahead to [01 Setup](/docs/notwork/01-setup).

## What's in it

- **RFCs.** Where the rules of the internet are written down, and how to read them.
- **Layers and encapsulation.** Why a network is built in layers, and how each one wraps the one above.
- **Addresses and links.** MAC, IP and port: which address does which job.
- **Packets on the wire.** Bytes, byte order, and how to read a header diagram.
- **The tools.** What tcpdump, Wireshark, `ip` and `ethtool` are for.

Each page ends with a short self-check.

<Recap title="By the end">
  - You can read an RFC header diagram.
  - You know which address does what.
  - You know what each tool is for.
</Recap>
