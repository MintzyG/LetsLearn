When you clicked the link to this page, your computer asked a DNS server where this site lives. It opened a connection to the server and sent a request for the page. That request was cut into packets, each packet was wrapped in a frame for your router, and router after router passed it across the internet. The page came back the same way, in pieces, and your computer put them back in order. All of that took a fraction of a second, and then you got to see this page.

Ever wondered how all of that works?

In this book, you build it yourself. Notwork is a network stack you write by hand, from Ethernet frames up to HTTP. When it's done, it fetches a real web page from the internet, and it serves a page your phone can load. Your laptop, your router and that server share no code, only the rules. Follow them, and your stack is a peer like any other.

## Requirements

- One Linux machine
- A network connection, wired or Wi-Fi
- A second machine (optional, but it makes showing off more fun)
- Your phone, for the final challenge

The tests and support code are in Go. You can follow the book in another language, but then you're on your own for the tests.

## What's in this book

Each chapter takes one protocol (big ones, like TCP, get a few chapters) and gives you:

- **The idea.** What the protocol is for and how it works, with a link to where it's written down, usually an RFC. You learn from the real spec, not just from the book.
- **What to build.** What your code must do, in plain words. The book tells you *what* to build, never *how*: shaping the code is your part.
- **The tests.** They tell you when it works. Run them as you go; when they all pass, you're done.
- **The show-off.** Then you try it on your real network, against your router, your phone or a real server.
- **The reference code.** It sits at the end of the chapter, folded away, for when you're done or stuck.
- **Challenges and deepenings.** Optional extras for when you want more: things to build with what you know now, and ways to dig deeper into the protocol. They come with tests too.

Every chapter ends with something that works. Stop anywhere, and you've still built something real.

## The road

## Not in this book

No IPv6, and no TLS, so no HTTPS. Notwork is a toy that works on the real thing: it follows the happy path, and each chapter says what a real stack does beyond it. It works on most networks, not all of them; some office networks lock things down.
